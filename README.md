## 📖 نظرة عامة

**طلبنا** هو تطبيق توصيل عربي كامل (RTL) مبني بـ:

- ⚛️ **React Native** + **Expo SDK 57**
- 🚏 **Expo Router** (File-based Routing)
- 🗄️ **Supabase** (Auth + DB + Storage + Realtime)
- 🎨 **TypeScript** (Strict Mode)

**الفكرة:** كل احتياجاتك.. في مكان واحد 🧺

---

## 🚀 البداية السريعة

### المتطلبات

- **Node.js** ≥ 20
- **pnpm** (Package Manager)
- **Expo Go** (للموبايل) أو **محاكي** Android/iOS
- حساب **Supabase**

### التثبيت

```bash
# 1. استنسخ المشروع
git clone <repo-url> talabnah
cd talabnah

# 2. ثبّت الحزم
pnpm install

# 3. أعدّ متغيرات البيئة (انظر قسم البيئة أدناه)
cp .env.example .env

# 4. طبّق SQL على Supabase (انظر قسم قاعدة البيانات)

# 5. شغّل
pnpm start
```
